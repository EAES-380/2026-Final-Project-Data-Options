# EAES 380 Final Project Dataset Options (from EDI)

Curated from the Environmental Data Initiative (EDI) data portal:  
https://portal.edirepository.org/

Three options are provided for each of the four departmental subject areas. Each dataset has its own short README.md in this folder with a direct link to the metadata page, basic description, coverage, and suggested analyses.

**Note on access:** Most EDI datasets can be downloaded directly from the metadata page (or via the generated R/Python code). Some require a free EDI access key for scripted downloads. Check the “Accessing Data” documentation on the EDI site if you encounter authentication prompts.

## How to use these READMEs

Share the individual README.md files (or this index) with students. Each contains the direct link to the EDI metadata landing page so students can explore data entities, download tables, and generate analysis code.

If a student needs help accessing a particular package, the package ID is listed above.
