How to choose a dataset

Use the dataset pages to compare options side by side. Each page tells you what the dataset is, where it comes from, what it contains, and which analyses it suits.

  1. Start with your interest. Pick the subject area closest to what you want to learn about, then read its three options.
  2. Check the coverage. Every page lists the time span and location. Look for a record long enough, or frequent enough, for your question (for example, 10-minute data supports diurnal cycles, while multi-decade records support trend analysis).
  3. Read the suggested analyses. Each page lists analyses the dataset supports. Ask whether one of them could become your project question.
  4. Check how easy it is to access. Open the EDI metadata page linked on each dataset page. If you hit an authentication prompt, see the access note above. MacroSheds also has an R package and a dashboard linked on its page.
  5. Ask for help if needed. The EDI package ID is listed on every page so you can point to the exact dataset.
